Página Web Nike

Sitio web inspirado en la marca Nike, desarrollado como práctica de frontend y backend completo. Incluye un diseño moderno, secciones interactivas y un sistema responsivo que se adapta a diferentes dispositivos. Además, cuenta con funcionalidades de usuario y administrador, carrito de compras y gestión de pedidos.

Roles y funcionalidades

  • Usuario: navegar productos, añadir al carrito, proceder a la compra, ver historial de pedidos.
  • Administrador: añadir, editar y eliminar productos, ver pedidos de todos los usuarios.
  • Autenticación: registro, login y control de roles con JWT.
  • Carrito: sincronización entre frontend y backend, actualización de cantidades, eliminación de productos.
  • Pedidos: creación de órdenes, seguimiento del estado y vaciado del carrito tras la compra.
  • Perfil: edición de información personal y gestión de pedidos.

Tecnologías utilizadas

  • HTML5 → estructura semántica del sitio
  • CSS3 → estilos modernos, responsive design y animaciones
  • JavaScript (ES6+) → interactividad en el frontend
  • Angular → desarrollo de componentes reutilizables y SPA
  • Node.js & npm → entorno de ejecución y gestión de dependencias
  • Express.js → configuración del backend y API REST
  • MySQL → gestión de base de datos y almacenamiento de usuarios/productos/pedidos
  • Git & GitHub → control de versiones y repositorio
  • Cypress → pruebas end-to-end para verificar funcionalidades

Cómo ejecutar el proyecto

  1. Clonar el repositorio: git clone https://github.com/Carlostarre/NikeCypress.git
  2. Instalar dependencias:
    • Frontend (Angular - carpeta pixar-web): npm install y npm install -g @angular/cli si no tienes Angular CLI.
    • Backend (Node.js - carpeta backend): npm install
  3. Configurar base de datos MySQL:
    • Abrir XAMPP y asegurarse de que MySQL esté iniciado.
    • Crear la base de datos: CREATE DATABASE nike_store;
    • Crear las tablas correspondientes ejecutando el script SQL incluido en el proyecto:
      • USE nike_store;

-- Tabla de usuarios
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    isAdmin BOOLEAN DEFAULT 0,
    createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabla de productos
CREATE TABLE products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    price DECIMAL(10,2) NOT NULL,
    stock INT DEFAULT 0,
    image VARCHAR(255),
    createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tabla carrito
CREATE TABLE cart (
    id INT AUTO_INCREMENT PRIMARY KEY,
    userId INT NOT NULL,
    productId INT NOT NULL,
    quantity INT DEFAULT 1,
    FOREIGN KEY (userId) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (productId) REFERENCES products(id) ON DELETE CASCADE
);

-- Tabla órdenes
CREATE TABLE orders (
    id INT AUTO_INCREMENT PRIMARY KEY,
    userId INT NOT NULL,
    status VARCHAR(50) DEFAULT 'Pending',
    createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (userId) REFERENCES users(id)
);

-- Tabla items de órdenes
CREATE TABLE order_items (
    id INT AUTO_INCREMENT PRIMARY KEY,
    orderId INT NOT NULL,
    productId INT NOT NULL,
    quantity INT DEFAULT 1,
    FOREIGN KEY (orderId) REFERENCES orders(id) ON DELETE CASCADE,
    FOREIGN KEY (productId) REFERENCES products(id) ON DELETE CASCADE
);
  4. Iniciar backend: npm start en la carpeta backend. Servidor disponible en http://localhost:3000.
  5. Iniciar frontend: ng serve en la carpeta pixar-web. Abrir http://localhost:4200 en el navegador.
  6. Configurar usuario administrador:
    • Crear un usuario desde la web.
    • Modificarlo a administrador en la base de datos MySQL: UPDATE users SET isAdmin = 1 WHERE email = 'tu-email@example.com';

🎮 FireplayGames

Plataforma web de exploración y gestión de videojuegos con autenticación, favoritos, carrito de juegos y datos del usuario integrados. Diseño moderno, responsive y dinámico, utilizando Firebase y la RAWG API.

Funcionalidades principales

  • Autenticación: registro e inicio de sesión con Firebase Auth
  • Catálogo de juegos: búsqueda avanzada por nombre, género, plataforma o fecha de lanzamiento
  • Favoritos: marcar juegos favoritos y almacenarlos en Firestore
  • Carrito de juegos: añadir juegos al carrito y gestionar la selección de manera interactiva
  • Perfil de usuario: ver y editar información personal, historial de favoritos y carrito
  • Detalles de juegos: información completa con capturas de pantalla, géneros, plataformas y calificaciones (RAWG API)
  • Responsive: adaptado a móviles, tablets y escritorio

Tecnologías utilizadas

  • Next.js → framework React con SSR y rutas dinámicas
  • React → componentes reutilizables e interactividad
  • TypeScript → tipado estático para mayor seguridad
  • Firebase → autenticación, Firestore para favoritos y carrito
  • RAWG API → obtención de datos de videojuegos
  • Tailwind CSS → diseño moderno y responsive
  • Vite / npm → build y gestión de dependencias
  • Git & GitHub → control de versiones y repositorio

Cómo ejecutar el proyecto

  1. Clonar el repositorio: git clone https://github.com/TU_USUARIO/FireplayGames.git
  2. Instalar dependencias: npm install
  3. Configurar variables de entorno: crear .env.local con Firebase y RAWG API
  4. Iniciar servidor de desarrollo: npm run dev. La app estará disponible en http://localhost:3000
  5. Probar la aplicación:
    • Registrar un usuario e iniciar sesión
    • Buscar juegos usando el buscador integrado
    • Agregar juegos a favoritos y al carrito
    • Visualizar detalles de los juegos y capturas de pantalla
    • Editar información del perfil

Características destacadas

  • 🎨 Diseño moderno: interfaz limpia y responsive con Tailwind CSS
  • 🔐 Seguridad: autenticación Firebase Auth y control de datos del usuario
  • ⚡ Interactividad: favoritos, carrito y buscador dinámico
  • 📱 Responsive: optimizado para móviles, tablets y escritorio
  • 🧩 Modular: componentes React reutilizables y mantenibles
